# Setting Up Elasticsearch and Kibana on Windows

Download both Elasticsearch & Kibana

- https://www.elastic.co/downloads/elasticsearch
- https://www.elastic.co/downloads/kibana

## To install elasticsearch

1. Download the files then copy them over to the directory of your choice.
2. Extract the files using `7z` for a better experience

## To start elasticsearch

Run:

```shell
bin\elasticsearch.bat
```

You will see output like:

```

✅ Authentication is enabled and cluster connections are encrypted.

  21064c64e4a2675df49c9ddb6e281105445ff153780eb9702817e5d70e2bbd09

❌ Unable to generate an enrollment token for Kibana instances, try invoking `bin/elasticsearch-create-enrollment-token -s kibana`.

  ⁃ Create an enrollment token with `bin/elasticsearch-create-enrollment-token -s node`.

  ⁃ Start Elasticsearch with `bin/elasticsearch --enrollment-token <token>`, using the enrollment token that you generated.
```

## To start Kibana

1. Create an enrollment token for kibana:

```shell
bin/elasticsearch-create-enrollment-token.bat --scope kibana
```

2. Start kibana:

```shell
$ bin/kibana.bat

i Kibana has not been configured.

Go to http://localhost:5601/?code=780426 to get started.
```

3. Open the url shown in the terminal via the browser of your choice, and paste the enrollment token created earlier.

4. Now log in using the credentials created earlier:
   - username: `elastic`
   - password: `zwDitFPJsDTqWgFTA7pn`

5. When asked to _Start by adding integrations_, choose _Explore on my own_
