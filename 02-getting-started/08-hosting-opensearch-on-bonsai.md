# Hosting OpenSearch on Bonsai

They offer a free account, free forever, without limits.

- Bonsai uses a multi-tenancy architecture, which come with a few limitations:
  - Certain features are disabled for security and performance reasons
  - A few of these featuers are demonstrated in the course
  - You will still be able to follow along for the vast majority of the course
- Index templates are disabled
- The UPdate by Query API is disabled
- Automatic index creation when indexing documents is disabled.
- https://bonsai.io/partner/bo-andersen-udemy

> Note:  
> use code **UDEMY** for **20% discount** on paid plans for 3 months.

After creating an account:

- Go to the access tab, under credentials you'll see a default cluster
- You will also see a URL, you'll need it.
  - Note that the URL has the credentials at the beginning. That is `HTTP Basic` Authentication.
- You can also use the UI Console to run the queries, so you might end up not needing to use the URL.
- Under settings, you can delete the cluster once you no longer need it.
